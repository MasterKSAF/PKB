# Методики экспериментов RAG

Структура проекта:

- `rag_experiments_methodology.md` — методика экспериментов: параметры чанкования, модели эмбеддингов, стратегии поиска, план запусков (3 фазы), метрики, структура утилиты
- `rag_evaluation_methodology.md` — методика оценки качества: составление эталонных запросов, разметка релевантности, перечень метрик, протокол статзначимости
