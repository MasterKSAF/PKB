# parser_docling — специфика

## Списки (.1, .2, 1.2.3)

Docling экспортирует `.1` через `- .1` (bullet + dotted number), а `.4` иногда вообще без маркера. 
Парсер `md_to_json.py`:
- Детектит `- .1` как numbered (из-за `rest.match(r'^\.?\d')`)
- Детектит `.4` (без `-`) через `r'^\.\d+(\.\d+)*'`
- Группировка: пропускает пустые строки внутри списка; разрывает при смене уровня (.1 → 1.2.3)

## Группировка коротких строк в list

Эвристика `_looks_like_list_item()`:
- Содержит ` - ` или ` — `
- Заглавная аббревиатура (2-10 символов, только заглавные)
- Условие группировки: ≥3 строк, все ≤120 символов, хотя бы одна `_looks_like_list_item`

## Оценка метрик

evaluate_quality.py разворачивает list-блоки в отдельные элементы с их bbox (`_flatten_blocks`),
чтобы сортировка по bbox работала корректно (иначе все элементы одного списка сортируются
в одну позицию по объединённому bbox).
