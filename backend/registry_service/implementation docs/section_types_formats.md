# Форматы рендеринга типов секций (Markdown & HTML5)

В данном документе приведено сопоставление того, как структуры данных каждого типа секции (`content` в формате JSON) должны быть представлены (отрендерены) в форматах **Markdown** и **HTML5**, с описанием назначения и примечаниями для каждого типа.

Во внешнем элементе HTML добавляется атрибут ```data-type="{type}"```.

---

## 1. `text` (Простой текст)

| Формат / Поле | Описание / Представление / Рендеринг |
| :--- | :--- |
| **Описание** | Используется для стандартных текстовых абзацев. |
| **JSON (`content`)** | `{"text": "Настоящий стандарт распространяется на...", "amendments": null}` |
| **Markdown** | `\n\nНастоящий стандарт распространяется на...` |
| **HTML5** | `<p>Настоящий стандарт распространяется на...</p>` |
| **Комментарии** | Базовый текстовый абзац. Поправки (`amendments`) рендерятся отдельно при их наличии. |

---

## 2. `textBlock` (Группа текстовых блоков)

| Формат / Поле | Описание / Представление / Рендеринг |
| :--- | :--- |
| **Описание** | Используется для сложной текстовой структуры или сгруппированных блоков. |
| **JSON (`content`)** | `{"block": ["Первый абзац блока.", "Второй абзац блока."]}` |
| **Markdown** | `\n\nПервый абзац блока.`<br><br>`Второй абзац блока.` |
| **HTML5** | `<section>`<br>`  <p>Первый абзац блока.</p>`<br>`  <p>Второй абзац блока.</p>`<br>`</section>` |
| **Комментарии** | Объединяет несколько текстовых блоков в единую логическую структуру. В HTML5 оборачивается в `<section>` для лучшей семантики. |

---

## 3. `headerFooter` (Колонтитулы)

| Формат / Поле | Описание / Представление / Рендеринг |
| :--- | :--- |
| **Описание** | Используется для верхних и нижних колонтитулов страниц. |
| **JSON (`content`)** | `{"text": "ГОСТ 20868-81 — Страница 4"}` |
| **Markdown** | `*ГОСТ 20868-81 — Страница 4*` (курсив) |
| **HTML5** | `<header class="header-footer">`<br>`  <span>ГОСТ 20868-81 — Страница 4</span>`<br>`</header>` |
| **Комментарии** | В Markdown выделяется курсивом (`*`). В HTML5 используется элемент `<header>` или `<footer>` в зависимости от реального расположения колонтитула.<br> **Лучше разбить этот тип на два: header и footer, по одному для верхних и нижних колонтитулов.** |

---

## 4. `table` (Таблицы)

| Формат / Поле | Описание / Представление / Рендеринг |
| :--- | :--- |
| **Описание** | Содержит структурированные табличные данные и метаданные. |
| **JSON (`content`)** | `{"caption": "Таблица 1 — Размеры", "columns": ["Ширина", "Высота"], "rows": [["100", "200"], ["150", "300"]], "footnotes": ["* Примечание: Размеры указаны в мм."], "image_key": "previews/1/tables/t1.png"}` |
| **Markdown** | `Таблица 1 — Размеры`<br>`\| Ширина \| Высота \|`<br>`\| :--- \| :--- \|`<br>`\| 100 \| 200 \|`<br>`\| 150 \| 300 \|`<br>`\* Примечание: Размеры указаны в мм.`<br><br>`![Таблица 1 — Размеры](/api/v1/files/previews/1/tables/t1.png)` |
| **HTML5** | `<table>`<br>`  <caption>Таблица 1 — Размеры</caption>`<br>`  <thead>`<br>`    <tr><th>Ширина</th><th>Высота</th></tr>`<br>`  </thead>`<br>`  <tbody>`<br>`    <tr><td>100</td><td>200</td></tr>`<br>`    <tr><td>150</td><td>300</td></tr>`<br>`  </tbody>`<br>`  <tfoot>`<br>`    <tr><td colspan="2">* Примечание: Размеры указаны в мм.</td></tr>`<br>`    <tr><td colspan="2">Источник: <a href="/api/v1/files/previews/1/tables/t1.png">Изображение источника</a></td></tr>`<br>`  </tfoot>`<br>`</table>` |
| **Комментарии** | В Markdown таблица рендерится в формате GFM с примечаниями под ней. В HTML5 заголовок таблицы рендерится с помощью тега `<caption>` непосредственно внутри `<table>`, а примечания, сноски (`footnotes`) и ссылка на изображение-источник размещаются в секции `<tfoot>`. <br> Ширина таблицы определяется по ширине в данных. Если данные ячейки отсутствуют, то ставиться пробел в md или ```&nbsp;``` в html5.|

## 5. `list` (Списки)

| Формат / Поле | Описание / Представление / Рендеринг |
| :--- | :--- |
| **Описание** | Представляет списки с определенным типом нумерации или маркеров. |
| **JSON (`content`)** | `{"numbering_style": "1", "items": ["Элемент один", "Элемент два"]}` |
| **Markdown** | `1. Элемент один`<br>`2. Элемент два` |
| **HTML5** | `<ol type="1">`<br>`  <li>Элемент один</li>`<br>`  <li>Элемент два</li>`<br>`</ol>` |
| **Комментарии** | Стиль списков (нумерованный или маркированный) определяется параметром `numbering_style` (например, `1`, `a`, `bullet`).<br>**В формате не указан номер и/или буква елементов списка, а также нет ссылки на список в json, потому все элементы будут отображаться как ``` * ``` (```bullet points```)**|

---

## 6. `image` (Иллюстрации / Рисунки)

| Формат / Поле | Описание / Представление / Рендеринг |
| :--- | :--- |
| **Описание** | Представляет графические элементы и схемы, вырезанные из документа. |
| **JSON (`content`)** | `{"caption": "Рисунок 2", "image_key": "previews/1/fig2.png", "description": "Схема электрическая"}` |
| **Markdown** | `![Рисунок 2](/api/v1/files/previews/1/fig2.png)`<br>`*Рисунок 2 — Схема электрическая*` |
| **HTML5** | `<div data-type="image">`<br>`  <figure>`<br>`    <img src="/api/v1/files/previews/1/fig2.png" alt="{caption}">`<br>`    <figcaption>{caption}</figcaption>`<br>`  </figure>`<br>`  <p>{description}</p>`<br>`</div>` |
| **Комментарии** | Изображение рендерится с подписью из поля `caption` и описанием `description`. В HTML5 оборачивается в `<div>` с атрибутом `data-type="image"`, содержащий `<figure>` с изображением и подписью, а также параграф `<p>` с описанием. |

---

## 7. `formula` (Формулы)

| Формат / Поле | Описание / Представление / Рендеринг |
| :--- | :--- |
| **Описание** | Используется для математических или физических формул с детализацией физических параметров. |
| **JSON (`content`)** | `{"latex": "E = mc^2", "meaning": "Закон массы и энергии", "image_key": "previews/1/formulas/eq1.png"}` |
| **Markdown** | `$$E = mc^2$$`<br>`*Физический смысл: Закон массы и энергии*`<br><br>`![Формула: E = mc^2](/api/v1/files/previews/1/formulas/eq1.png)` |
| **HTML5** | `<section class="formula-container">`<br>`  <span class="latex">$$E = mc^2$$</span>`<br>`  <p><em>Физический смысл: Закон массы и энергии</em></p>`<br>`  <figure>`<br>`    <img src="/api/v1/files/previews/1/formulas/eq1.png" alt="Закон массы и энергии">`<br>`  </figure>`<br>`</section>` |
| **Комментарии** | LaTeX-представление обрамляется символами `$$` для блочной формулы. Дополнительно может отображаться изображение-вырезка формулы из MinIO.
