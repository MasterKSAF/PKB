# Спецификация типов секций документа (`section_types`)

В системе для структурных блоков (секций) документа в таблице `registry.document_sections` определены следующие основные типы (`type`) и соответствующая им структура поля `content` (JSONB):

---

## 1. `text` (Простой текст)
Используется для стандартных текстовых абзацев.

* **Структура `content`:**
  ```json
  {
    "text": "Текстовое содержимое абзаца...",
    "amendments": null // или массив поправок/изменений
  }
  ```

---

## 2. `textBlock` (Группа текстовых блоков)
Используется для сложной текстовой структуры или сгруппированных блоков.

* **Структура `content`:**
  ```json
  {
    "block": [
      // Массив вложенных блоков или элементов
    ]
  }
  ```

---

## 3. `headerFooter` (Колонтитулы)
Используется для верхних и нижних колонтитулов страниц.

* **Структура `content`:**
  ```json
  {
    "text": "ГОСТ 20868-81 Страница 3"
  }
  ```

---

## 4. `table` (Таблицы)
Содержит структурированные табличные данные и метаданные.

* **Структура `content`:**
  ```json
  {
    "caption": "Таблица 1 — Физико-механические показатели",
    "columns": ["Показатель", "Значение"],
    "rows": [
      ["Прочность на растяжение, МПа", "250"],
      ["Относительное удлинение, %", "15"]
    ],
    "footnotes": [], // сноски к таблице
    "amendments": [], // поправки к таблице
    "image_key": "previews/1/tables/t1.png" // ссылка на вырезанное изображение таблицы в MinIO
  }
  ```

---

## 5. `list` (Списки)
Представляет списки с определенным типом нумерации или маркеров.

* **Структура `content`:**
  ```json
  {
    "numbering_style": "1", // или "a", "bullet" и т.д.
    "items": [
      "первый элемент списка",
      "второй элемент списка"
    ]
  }
  ```

---

## 6. `image` (Иллюстрации / Рисунки)
Представляет графические элементы и схемы, вырезанные из документа.

* **Структура `content`:**
  ```json
  {
    "caption": "Рисунок 2 — Схема подключения",
    "image_key": "previews/1/fig2.png", // ссылка на изображение в MinIO
    "description": "Схема электрическая принципиальная..." // описание рисунка
  }
  ```

---

## 7. `formula` (Формулы)
Используется для математических или физических формул с детализацией физических параметров.

* **Структура `content`:**
  ```json
  {
    "latex": "E = mc^2",
    "meaning": "Закон взаимосвязи массы и энергии",
    "image_key": "previews/1/formulas/eq1.png", // опциональное изображение формулы
    "parameters": [
      {
        "symbol": "E",
        "description": "Энергия",
        "unit": "Дж",
        "value": 100.0
      },
      {
        "symbol": "m",
        "description": "Масса",
        "unit": "кг",
        "value": 1.0
      }
    ]
  }
  ```
