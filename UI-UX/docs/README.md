# UI/UX Docs

Эта папка содержит рабочие и исторические документы UI/UX-команды.

## Важно

Актуальная документация по текущему интерфейсу находится не здесь, а в:

```text
../UI Final/docs
```

Актуальный frontend находится в:

```text
../UI Final/frontend
```

Эта папка `UI-UX/docs` в основном хранит материалы ранних этапов: workflow, роли, чек-листы, старые планы адаптации UI v1 и контекст по проекту.
