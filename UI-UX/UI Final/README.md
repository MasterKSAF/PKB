# UI Final

Объединенная версия интерфейса UI/UX для PKB Neuroassistant. Ветка предназначена для сборки итогового рабочего варианта на основе согласованных решений UI/UX-группы.

Интерфейс работает в демонстрационном режиме без backend и в продуктивном режиме через Gateway. Основной локальный порт UI — `3300`, основной локальный Gateway URL — `http://127.0.0.1:8081/api/v1`.

## Что находится в папке

| Путь | Что это |
| --- | --- |
| `frontend/` | Рабочее React-приложение объединенного интерфейса. Здесь исходный код, Dockerfile, nginx-конфиг, Vite, MUI и mock-данные. |
| `docs/first-run-ui-final.md` | Короткая инструкция первого запуска локально через Docker или npm. |
| `docs/first-run-ui-final-with-gateway.md` | Инструкция, как одновременно забрать актуальный Gateway и UI Final, запустить их локально и проверить стыковку. |
| `docs/ui-final-gateway-current-status-2026-06-03.md` | Исторический статус экспериментального подключения UI Final к Gateway на 03.06. |
| `docs/ui-final-gateway-open-items-2026-06-12.md` | Что осталось доделать в UI/Gateway-связке и какие вопросы нужно уточнить у backend. |

## Основные экраны

- `Вход`: логин, пароль, выбор продуктивного или demo-режима.
- `Чат`: вопросы инженера, ответы ассистента, источники, предпросмотр страниц и документов, поиск по текущему чату, обратная связь.
- `База знаний`: поиск по базе знаний, разделы Registry/Classifiers, провал в раздел, список документов, предпросмотр и поиск внутри открытого документа.
- `Обработка базы знаний`: загрузка файла, черновики, preview, approve/reject, очередь и журнал обработки.
- `История`: поиск по диалогам, фильтры, раскрытие найденного диалога.
- `QA`: контрольные метрики, оценка ответов ассистента, журнал проверки.
- `Администрирование`: пользователи, роли, права, журналы и служебные настройки.

## Быстрый запуск

Если нужно забрать только эту версию, используйте ZIP ветки или sparse checkout из `docs/first-run-ui-final.md`.
Если нужно проверить связку UI Final + Gateway, используйте `docs/first-run-ui-final-with-gateway.md`.

```bash
git checkout feature/ui-final-api-gap-adaptation
cd "UI-UX/UI Final/frontend"
docker compose up --build
```

После запуска открыть:

```text
http://localhost:3300
```

Альтернативный запуск для разработки:

```bash
npm ci
npm run dev -- --host 127.0.0.1 --port 3300 --strictPort
```

Открыть:

```text
http://127.0.0.1:3300
```

## Текущее состояние

- UI собран как основная рабочая версия для стыковки с Gateway.
- Основной переходник к Gateway находится в `frontend/src/utils/http.ts`.
- Чат, база знаний, обработка базы знаний, история, QA и часть администрирования уже подключены к актуальному Gateway.
- Поиск по базе знаний находится внутри вкладки `База знаний`.
- В продуктивном режиме UI не должен молча показывать demo-данные при ошибке Gateway; допустимы controlled empty/error states и явно помеченные fallback-сценарии.
- Сценарий `Проверка` исключен из UI Final: для него нет API-контрактов Gateway, и сейчас он не планируется к интеграции.
- Инструкция запуска связки UI + Gateway описана в `docs/first-run-ui-final-with-gateway.md`.
- `npm run build`, `npm run lint` и Gateway API tests проверены.
- Актуальный список остаточных вопросов описан в `docs/ui-final-gateway-open-items-2026-06-12.md`.
