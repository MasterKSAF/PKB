# Frontend V1

Архивная первая версия интерфейса.

## Важно

Эта папка больше не является основной рабочей версией UI.

Актуальный интерфейс находится здесь:

```text
../UI Final/frontend
```

Актуальная документация:

```text
../UI Final/README.md
../UI Final/frontend/README.md
../UI Final/docs
```

Актуальная ветка:

```text
develop
```

## Для чего оставлена папка

`frontend-v1` оставлен только как исторический материал раннего UI:

1. старые макеты и сценарии;
2. ранняя структура компонентов;
3. старые mock-данные;
4. исторический контекст по UI v1.

Новые правки, интеграцию с Gateway, документацию запуска и backend-блокеры нужно вести в `UI Final`.

## Запуск

Запуск этой версии не поддерживается как основной сценарий. Для запуска актуального интерфейса используйте:

```powershell
cd "../UI Final/frontend"
npm ci
npm run dev -- --host 127.0.0.1 --port 3300 --strictPort
```

Открыть:

```text
http://127.0.0.1:3300
```
