# UI/UX

Рабочая зона UI/UX-направления проекта `PKB_neuroassistant`.

## Актуальное состояние

Основная рабочая версия интерфейса находится здесь:

```text
UI-UX/UI Final/frontend
```

Актуальная ветка для UI и размещения на сервере:

```text
develop
```

Локальный порт актуального UI:

```text
http://127.0.0.1:3300
```

Локальный Gateway для проверки:

```text
http://127.0.0.1:8081/api/v1
```

## Что здесь лежит

| Папка | Статус | Что внутри |
| --- | --- | --- |
| `UI Final/` | Актуально | Основной UI Final, документация, инструкция запуска, frontend-код и актуальные блокеры backend. |
| `meetings/` | Актуально | MEMO встреч и ссылки на видеозаписи. |
| `docs/` | Частично историческое | Старые материалы UI/UX-команды, чек-листы, роли, workflow и планы по ранним версиям интерфейса. |
| `frontend-v1/` | Архив | Первая версия интерфейса, больше не является основной рабочей версией. |
| `frontend-v2/` | Архив/эксперимент | Экспериментальная зона, не используется как основной UI. |

## Что сейчас умеет UI Final

1. Работает в demo-режиме и продуктивном режиме через Gateway.
2. Поддерживает вход, роли и права через профиль пользователя.
3. Содержит вкладки: чат, база знаний, обработка базы знаний, история, QA и администрирование.
4. В базе знаний есть разделы, провал в раздел, список документов, поиск и предпросмотр.
5. В обработке базы знаний есть вложенные зоны: загрузка, черновики, реестр документов и журналы.
6. Поддержана прямая файловая загрузка документов, в том числе несколько файлов.
7. Есть работа с черновиками, метаданными, JSON, классификацией, approve/reject/delete.
8. Добавлен реестр документов с предпросмотром, сроком действия и действиями документа.
9. В администрировании добавлены редакторы классификаторов, терминологии и неизвестных кодов.
10. Открытые вопросы к backend вынесены в отдельный MD-файл.

## Как работаем с ветками

Основная ветка проекта:

```text
develop
```

Для текущей стадии проекта актуальный UI должен находиться в `develop`. Старые экспериментальные ветки и папки не считаются источником истины, если нужные материалы уже перенесены в `develop`.

## Что не коммитим

- `node_modules`;
- `dist`;
- временные файлы;
- локальные `.env`;
- локальные логи Gateway;
- большие видеофайлы;
- скриншоты и черновики без необходимости.

Видео встреч храним вне GitHub. В репозитории оставляем MEMO и ссылку на запись.
